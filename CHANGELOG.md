# Changelog

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added (Phase 3: feature engineering)
- `features.py`: W970 = A970 - A940; thermal ΔT, CWSI, temperature spread; FAO-56 VPD; `positional_contrasts` for 3 or 4 positions; `baseline_change` (vs day -1) and causal `recent_slope` (last 3 measurement days)
- `feature_table.build_features`: plant/day table from validated tables; calibration against session references, repeat and position averaging, QC exclusions left out and counted, missing positions give NaN
- `registry.py`: name, unit, sensor, equation and reference for every column; `docs/features.md` generated by `scripts/build_feature_docs.py` with freshness test
- `scripts/build_features.py` writes immutable `features.parquet`
- Hand-calculated unit tests for every equation

### Unchanged
- `spectral_features` and `positional_features` signatures and outputs (shim kept)

## Phase 2

### Added (Phase 2: data contract, ingestion and QC)
- `leafy_ai.schemas`: pandera schemas for plants, clip_readings, references, thermal, images, ground_truth; columns follow preset bands, LEDs, positions and sensors
- `docs/data-schema.md` generated by `scripts/build_schema_docs.py`; test fails when stale
- `leafy_ai.io`: load CSV or Parquet exports, validate, check plant and session links, join plant/day, write read only interim Parquet with SHA-256 manifest; changed content refuses to overwrite
- `leafy_ai.qc`: flags saturation, negative counts, white drift, temperature drift, repeat CV, missing positions and images without colour checker; pre-registered `qc` block in presets; HTML and CSV reports; rows never dropped
- `leafy_ai.colour_correction`: 24 patch checker detection and 3×3 linear sRGB correction matrix against colour-science reference values
- `leafy_ai.segmentation`: excess green + Otsu leaf mask and background removed variant
- `scripts/ingest.py`, `scripts/process_images.py`
- `[image]` extra; pandera and pyarrow in core

## Phase 1

### Added
- Phase 1: `configs/presets/` YAML for `root_disease`, `xcc` and `salt_planb` with pydantic loader `leafy_ai.config.load_config`
- GitHub Actions CI: ruff lint and format check, pytest on Ubuntu and Windows, Python 3.11 to 3.13, CPU only, synthetic smoke test, cached checkpoint smoke test
- `.gitignore`, pre-commit, `CONTRIBUTING.md`, `CITATION.cff`, issue and PR templates, `CODEOWNERS`
- `pyproject.toml` extras `[vision]`, `[stats]`, `[export]`, `[dev]`, `[all]`
- `scripts/smoke_test.py --skip-checkpoints` for runs without downloaded weights

### Changed
- `leafy_ai.CLASSES` now reads default `xcc` preset; value unchanged
- Core install no longer pulls PyTorch; use `[vision]` extra
- Platform neutral install docs; personal paths removed
- Code formatted with ruff; no behaviour change
